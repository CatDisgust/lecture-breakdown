# 课件知识点拆分

复习策略分三步：① 理解重要知识点 → ② 做一遍样卷，弄清考什么 → ③ 做专项练习。这个 skill 只负责第 ① 步：把一份课件拆成知识点，帮用户真正理解。出题、刷题、押题不在这里做；只给出“考法预判”，留给第 ② 步验证。

## 输入

- 一份或几份课件：PDF、PPTX 或截图。一次处理一讲（一个 lecture / 一周）。
- 可选：课程代码、考试形式（闭卷 / 开卷 / 限制开卷），已经卡住的地方。

没给考试形式时，先问一句；对方不知道就按闭卷处理。

## 第 1 步：读完整份课件

- 每一页都要读，包括图、表、公式和讲者备注。读取方式按环境来：有处理 PDF / PPTX 的 skill 就用它；没有的话直接读文件，或用命令行工具提取文字（如 `pdftotext`、`python-pptx`）。
- 图片型页面（图、流程图、截图里的公式）不能只读提取出来的文字。能看图就直接看；需要的话先把那一页渲染成图片再看。实在看不到图时，要告诉用户哪几页没看到，不要凭页面标题猜内容。
- 记下每个内容所在的页码，后面所有知识点都要标出处。
- 跳过纯行政页（课程安排、作业截止日期、致谢等），但如果有“考试会考 / important / key takeaway”之类的提示，要记下来。

## 第 2 步：拆知识点

**粒度**：一个知识点 = 一个能被单独考到的概念、机制、方法或公式。一讲通常拆成 6–15 个。

- 例子、动机页、过渡页并入它们所服务的知识点，不单独成点。
- 同一个概念分散在几页的，合并成一个点，标出全部页码。
- 一个点如果需要三段以上才能讲清楚，就拆成两个。

**重要度**，三档：

| 档位 | 判断信号 |
|---|---|
| 核心 | 讲者花了多页；有公式、算法步骤或完整例题；出现在总结页；被标为 key / important；和 tutorial、作业直接相关 |
| 重要 | 支撑核心点的概念；有对比表或定义框 |
| 了解 | 背景、历史、扩展阅读、一笔带过的内容 |

每个点给出判断依据（例如：“p.12–15 共 4 页 + 总结页再次出现”），不要凭感觉打分。

**排序**：按依赖关系排，先讲前置知识，不按页码顺序。

## 第 3 步：先给一张知识地图

先输出一张总览，让用户一眼看清这一讲的结构，然后再进入细节：

```
## Lecture X：<主题>（共 N 个知识点）

| # | 知识点（English term） | 重要度 | 依据 | 依赖 | 页码 |
|---|---|---|---|---|---|
| 1 | ... | 核心 | ... | — | p.3–6 |
| 2 | ... | 重要 | ... | 1 | p.7 |

建议顺序：1 → 2 → 4 → 3 …
时间有限时，只学“核心”档。
```

知识点之间有分支或汇合关系，表格又说不清的时候，可以加一张简图。默认用缩进树，在终端里也能看；界面能渲染 Mermaid 时可以改用 Mermaid。

## 第 4 步：逐个讲透

默认从第一个核心点开始；用户指定了起点就从那里开始。每次讲一个点，格式固定：

```
### <#>. <知识点>（<English term>）· <重要度> · p.<页码>

**一句话**：它是什么。
**解决什么问题**：没有它会怎样，为什么要发明它。
**怎么运作**：机制、步骤，或者公式里每一项的含义。
**最小例子**：最小的具体例子。优先用课件里的；课件里没有，就自己编一个并标注（课件外补充）。
**易错点**：学生最容易混淆或误解的 1–2 处，以及和相邻概念的区别。
**考法预判**：最可能怎么考（定义 / 比较 / 计算 / 应用场景 / 画图），一行。
**自测**：一道小题，答案先不给。
```

讲完等用户答自测题：

- **答对**：用一句话确认，指出他答案里最关键的那一点，然后进入下一个知识点。
- **答错或说不会**：判断卡在哪：前置概念缺失、两个概念混淆，还是机制没想通。只补卡住的那一环，不要整段重讲；补完换个角度再问一次。环境里装了 aha skill 时，在卡点上调用它；没装就按这里的规则处理。
- 追问最多两轮。两轮之后还没通，就直接把答案讲清楚，把这一点记入“卡点记录”，然后继续往下讲，不要一直追问。

用户说“快速过”时，跳过自测，连续讲完所有核心点，最后统一出 3–5 道自测题。

## 第 5 步：本讲收尾

讲完或用户喊停时，输出：

1. **已掌握**：自测通过的知识点。
2. **卡点记录**：没通的点，以及具体卡在哪一环，做样卷之前要回头再看。
3. **留给样卷验证**：各个“考法预判”汇总成一张清单，第 ② 步做样卷时逐条核对是否真的这样考。
4. **按考试形式补一项**：
   - **开卷 / 限制开卷**：A4 笔记候选条目。只收翻书也想不起来的内容（公式、步骤、对比表），每条一行。
   - **闭卷**：必背清单（定义、公式、算法步骤），每条一行，方便默写。

## 规则

- **只以课件为准**。课件外的补充解释、例子要标注（课件外补充）；和课件说法冲突时，以课件为准并指出差异。
- **术语保留英文**：考试是英文的。中文讲解，关键术语第一次出现时写成“中文（English）”，之后可以只写英文。
- **讲解不是翻译**：不要逐页复述课件。每个点都要回答“为什么”和“怎么运作”。
- **简短**：每个知识点的讲解控制在一屏左右。用户想深入时再展开。
- **不出整套题**：样卷和专项练习是后两步的事，这里只给自测小题和考法预判。
